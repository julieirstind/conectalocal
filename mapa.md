# Tela: Mapa

## Objetivo
Localizar o comércio e orientar o cliente até o ponto desejado.

## Elementos

- Mapa centralizado
- Marcador da localização do comércio
- Botão "Abrir no Maps"
- Botão "Comércio Local"

## Cores

- #A9D9D0
- #FFFFFF

## Navegação

### Botão Abrir no Maps
Abre ferramentas de navegação externa do sistema.

### Botão Comércio Local
Retorna para informações do comércio.
