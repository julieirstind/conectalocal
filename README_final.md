# ConectaLocal

## Descrição
Projeto Flutter para apresentar uma experiência de localização e perfil de loja local, com navegação entre telas e visual inspirado em um protótipo de comércio local.

## Telas incluídas
- Tela de localização
- Tela de perfil da loja
- Tela de rota/como chegar

## Fluxo do app
1. A tela inicial mostra a localização.
2. O usuário clica em "Comércio Local".
3. A tela de perfil da loja é aberta.
4. O usuário clica em "Como chegar".
5. A tela de rota é aberta com informações da loja.
