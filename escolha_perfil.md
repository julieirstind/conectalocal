# Tela: Escolha de Perfil

## Objetivo
Permitir que o usuário escolha seu tipo de acesso.

## Elementos

- Logo
- Botão Sou Cliente
- Botão Sou Empreendedor

## Navegação

### Sou Cliente
Abre: Home Cliente

O que mostra:

- Lista de comércios locais
- Categorias
- Promoções

### Sou Empreendedor
Abre: Dashboard/Menu

O que mostra:

- Indicadores
- Projetos
- Mensagens
