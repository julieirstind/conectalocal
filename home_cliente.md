# Tela: Home Cliente

## Objetivo
Permitir descobrir negócios locais próximos.

## Elementos

- Campo de busca
- Categorias
- Lista de comércios
- Barra de navegação

## Navegação

- Informações do comércio
- Avaliações de usuários

### Ícone mapa

O que mostra:
